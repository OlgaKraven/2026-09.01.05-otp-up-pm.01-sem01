V04-01 · В форме не прикрепляется PDF

На рабочем месте пользователь сообщает: «В форме не прикрепляется PDF». После повторения действия отображается тот же симптом; перезапуск вкладки результата не изменил. Ожидается, что операция «в форме не прикрепляется pdf» будет обработана штатно либо сервис покажет понятное ограничение.

Канал: email. Контакт: Учебный пользователь 04-01.

Предоставлено: Форма принимает PDF до 2 МБ. anketa.pdf в реестре имеет размер 3 МБ; тип PDF подтверждён условиями случая.

V04-02 · В форме не прикрепляется PDF

На учебном ноутбуке пользователь сообщает: «В форме не прикрепляется PDF». Проблема наблюдается только в учебных данных этого пользователя; у соседа действие выполняется. Ожидается, что операция «в форме не прикрепляется pdf» будет обработана штатно либо сервис покажет понятное ограничение.

Канал: телефон. Контакт: Учебный пользователь 04-02.

Предоставлено: Отдельный случай второго пользователя. Форма принимает PDF до 2 МБ. anketa.pdf в реестре имеет размер 3 МБ; тип PDF подтверждён условиями случая. Самостоятельная проверка на его рабочем месте ещё не выполнена.

V04-03 · В форме не прикрепляется PDF

На браузере учебного профиля пользователь сообщает: «В форме не прикрепляется PDF». До последнего штатного завершения работы функция открывалась без сообщения об ошибке. Ожидается, что операция «в форме не прикрепляется pdf» будет обработана штатно либо сервис покажет понятное ограничение.

Канал: портал. Контакт: Учебный пользователь 04-03.

Предоставлено: Отдельный случай третьего пользователя. Причина из обращения 01 для него не подтверждена. Уточнить объект, время появления и недавнее изменение; одинаковая тема не доказывает одинаковую причину.

Ожидается, что операция «не приходит уведомление о регистрации» будет обработана штатно либо сервис покажет понятное ограничение.

Канал: внутренний чат. Контакт: Учебный пользователь 04-04.

Предоставлено: M-01 «Учебное подтверждение» находится в папке «Спам», M-02 «Приглашение» — в «Рассылки». Реальная почта не используется.

Ожидается, что операция «не приходит уведомление о регистрации» будет обработана штатно либо сервис покажет понятное ограничение.

Предоставлено: M-01 «Учебное подтверждение» находится в папке «Спам», M-02 «Приглашение» — в «Рассылки». Реальная почта не используется. Проверка на рабочем месте пользователя 05 отдельно не выполнена.

Канал: телефон. Контакт: Учебный пользователь 04-07.

V04-10 · Форма открыта по устаревшей ссылке

На резервном рабочем месте пользователь сообщает: «Форма открыта по устаревшей ссылке». В сообщении нет признаков изменения реальных данных или оборудования; требуется безопасная проверка. Ожидается, что операция «форма открыта по устаревшей ссылке» будет обработана штатно либо сервис покажет понятное ограничение. В обращении намеренно отсутствует один существенный параметр, указанный в теме; его нужно запросить до вывода.

Канал: форма поддержки. Контакт: Учебный пользователь 04-10.

Предоставлено: Существенное условие намеренно не сообщено: Форма открыта по устаревшей ссылке. Уточнить его до вывода о причине. Объяснить, как полученный ответ повлияет на дальнейшую проверку.
