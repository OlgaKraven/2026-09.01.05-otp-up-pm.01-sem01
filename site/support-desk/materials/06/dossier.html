Досье · Копировальный центр

V06-01 · PDF печатается с неправильным масштабом

На браузере учебного профиля пользователь сообщает: «PDF печатается с неправильным масштабом». После повторения действия отображается тот же симптом; перезапуск вкладки результата не изменил. Ожидается, что операция «pdf печатается с неправильным масштабом» будет обработана штатно либо сервис покажет понятное ограничение.

Канал: email. Контакт: Учебный пользователь 06-01.

Предоставлено: Контрольный отрезок 100 мм выводится при масштабе 110 %. Исходный текст присутствует в макете.

V06-02 · PDF печатается с неправильным масштабом

На тестовом терминале пользователь сообщает: «PDF печатается с неправильным масштабом». Проблема наблюдается только в учебных данных этого пользователя; у соседа действие выполняется. Ожидается, что операция «pdf печатается с неправильным масштабом» будет обработана штатно либо сервис покажет понятное ограничение.

Канал: телефон. Контакт: Учебный пользователь 06-02.

Предоставлено: Отдельный случай второго пользователя. Контрольный отрезок 100 мм выводится при масштабе 110 %. Исходный текст присутствует в макете. Самостоятельная проверка на его рабочем месте ещё не выполнена.

V06-03 · PDF печатается с неправильным масштабом

На резервном рабочем месте пользователь сообщает: «PDF печатается с неправильным масштабом». До последнего штатного завершения работы функция открывалась без сообщения об ошибке. Ожидается, что операция «pdf печатается с неправильным масштабом» будет обработана штатно либо сервис покажет понятное ограничение.

Канал: портал. Контакт: Учебный пользователь 06-03.

Предоставлено: Отдельный случай третьего пользователя. Причина из обращения 01 для него не подтверждена. Уточнить объект, время появления и недавнее изменение; одинаковая тема не доказывает одинаковую причину.

V06-04 · В очереди остаются задания без результата

Ожидается, что операция «в очереди остаются задания без результата» будет обработана штатно либо сервис покажет понятное ограничение.

Канал: внутренний чат. Контакт: Учебный пользователь 06-04.

Предоставлено: В очереди собственное J-01 и чужие J-02/J-03. J-01 ожидает, принтер приостановлен.

На учебном ноутбуке пользователь сообщает: «В очереди остаются задания без результата». В сообщении нет признаков изменения реальных данных или оборудования; требуется безопасная проверка. Ожидается, что операция «в очереди остаются задания без результата» будет обработана штатно либо сервис покажет понятное ограничение.

Канал: форма поддержки. Контакт: Учебный пользователь 06-05.

Ожидается, что операция «двусторонняя печать переворачивает лист» будет обработана штатно либо сервис покажет понятное ограничение.

Канал: email. Контакт: Учебный пользователь 06-06.

Предоставлено: Досье: исходный документ содержит нижнюю строку; масштаб 110 %, формат вывода меньше макета. Физическая печать не проверялась. Модель print-lab.html показывает только влияние масштаба на границы страницы.

V06-07 · Не открывается файл макета

На тестовом терминале пользователь сообщает: «Не открывается файл макета». Проблема наблюдается только в учебных данных этого пользователя; у соседа действие выполняется. Ожидается, что операция «не открывается файл макета» будет обработана штатно либо сервис покажет понятное ограничение.

Канал: телефон. Контакт: Учебный пользователь 06-07.

Предоставлено: Досье: доступны только исходное сообщение и учебный контакт. Уточнить точный файл или адрес, версию программы, действие и сообщение. Проверку чужого устройства или внешней системы без доступа не объявлять выполненной.

V06-09 · Пользователь просит удалить чужие задания

На рабочем месте пользователь сообщает: «Пользователь просит удалить чужие задания». Пользователь выполнил действие дважды и остановился, чтобы не повредить учебные данные. Ожидается, что операция «пользователь просит удалить чужие задания» будет обработана штатно либо сервис покажет понятное ограничение.

V06-10 · Не указана модель печатающего устройства

На учебном ноутбуке пользователь сообщает: «Не указана модель печатающего устройства». В сообщении нет признаков изменения реальных данных или оборудования; требуется безопасная проверка. Ожидается, что операция «не указана модель печатающего устройства» будет обработана штатно либо сервис покажет понятное ограничение. В обращении намеренно отсутствует один существенный параметр, указанный в теме; его нужно запросить до вывода.

Канал: форма поддержки. Контакт: Учебный пользователь 06-10.

Предоставлено: Существенное условие намеренно не сообщено: Не указана модель печатающего устройства. Уточнить его до вывода о причине. Объяснить, как полученный ответ повлияет на дальнейшую проверку.
