V09-01 · В карточке ремонта не открывается фото

На рабочем месте пользователь сообщает: «В карточке ремонта не открывается фото». После повторения действия отображается тот же симптом; перезапуск вкладки результата не изменил. Ожидается, что операция «в карточке ремонта не открывается фото» будет обработана штатно либо сервис покажет понятное ограничение.

Канал: email. Контакт: Учебный пользователь 09-01.

Предоставлено: В реестре вложений photo.jpg имеет размер 0 байт. Право чтения карточки выдано.

V09-02 · В карточке ремонта не открывается фото

На учебном ноутбуке пользователь сообщает: «В карточке ремонта не открывается фото». Проблема наблюдается только в учебных данных этого пользователя; у соседа действие выполняется. Ожидается, что операция «в карточке ремонта не открывается фото» будет обработана штатно либо сервис покажет понятное ограничение.

Канал: телефон. Контакт: Учебный пользователь 09-02.

Предоставлено: Отдельный случай второго пользователя. В реестре вложений photo.jpg имеет размер 0 байт. Право чтения карточки выдано. Самостоятельная проверка на его рабочем месте ещё не выполнена.

V09-03 · В карточке ремонта не открывается фото

На браузере учебного профиля пользователь сообщает: «В карточке ремонта не открывается фото». До последнего штатного завершения работы функция открывалась без сообщения об ошибке. Ожидается, что операция «в карточке ремонта не открывается фото» будет обработана штатно либо сервис покажет понятное ограничение.

Канал: портал. Контакт: Учебный пользователь 09-03.

Предоставлено: Отдельный случай третьего пользователя. Причина из обращения 01 для него не подтверждена. Уточнить объект, время появления и недавнее изменение; одинаковая тема не доказывает одинаковую причину.

Канал: внутренний чат. Контакт: Учебный пользователь 09-04.

Предоставлено: Пользователь client02 открывает заявку client01. Матрица разрешает клиенту только собственные заявки.

Ожидается, что операция «пользователь не видит свою заявку» будет обработана штатно либо сервис покажет понятное ограничение.

Канал: форма поддержки. Контакт: Учебный пользователь 09-05.

Предоставлено: Пользователь client02 открывает заявку client01. Матрица разрешает клиенту только собственные заявки. Проверка на рабочем месте пользователя 05 отдельно не выполнена.

V09-08 · Не печатается квитанция

На браузере учебного профиля пользователь сообщает: «Не печатается квитанция». До последнего штатного завершения работы функция открывалась без сообщения об ошибке. Ожидается, что операция «не печатается квитанция» будет обработана штатно либо сервис покажет понятное ограничение.

V09-09 · Запрошена выдача данных другого клиента

На тестовом терминале пользователь сообщает: «Запрошена выдача данных другого клиента». Пользователь выполнил действие дважды и остановился, чтобы не повредить учебные данные. Ожидается, что операция «запрошена выдача данных другого клиента» будет обработана штатно либо сервис покажет понятное ограничение.

Канал: внутренний чат. Контакт: Учебный пользователь 09-09.

Предоставлено: Подтверждения полномочий на чужие данные, изменение прав или отключение защиты нет. Действие не выполнять; сформулировать границу и передачу уполномоченному специалисту.

V09-10 · Не указана версия программы

На резервном рабочем месте пользователь сообщает: «Не указана версия программы». В сообщении нет признаков изменения реальных данных или оборудования; требуется безопасная проверка. Ожидается, что операция «не указана версия программы» будет обработана штатно либо сервис покажет понятное ограничение. В обращении намеренно отсутствует один существенный параметр, указанный в теме; его нужно запросить до вывода.

Канал: форма поддержки. Контакт: Учебный пользователь 09-10.

Предоставлено: Существенное условие намеренно не сообщено: Не указана версия программы. Уточнить его до вывода о причине. Объяснить, как полученный ответ повлияет на дальнейшую проверку.
