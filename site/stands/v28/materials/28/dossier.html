V28-01 · CSV открывается с неверным разделителем

На резервном рабочем месте пользователь сообщает: «CSV открывается с неверным разделителем». После повторения действия отображается тот же симптом; перезапуск вкладки результата не изменил. Ожидается, что операция «csv открывается с неверным разделителем» будет обработана штатно либо сервис покажет понятное ограничение.

Канал: email. Контакт: Учебный пользователь 28-01.

Предоставлено: sample.csv использует «;», импортёр выбрал запятую. Измерения изменять нельзя.

V28-02 · CSV открывается с неверным разделителем

Ожидается, что операция «csv открывается с неверным разделителем» будет обработана штатно либо сервис покажет понятное ограничение.

Канал: телефон. Контакт: Учебный пользователь 28-02.

Предоставлено: Отдельный случай второго пользователя. sample.csv использует «;», импортёр выбрал запятую. Измерения изменять нельзя. Самостоятельная проверка на его рабочем месте ещё не выполнена.

V28-03 · CSV открывается с неверным разделителем

На учебном ноутбуке пользователь сообщает: «CSV открывается с неверным разделителем». До последнего штатного завершения работы функция открывалась без сообщения об ошибке. Ожидается, что операция «csv открывается с неверным разделителем» будет обработана штатно либо сервис покажет понятное ограничение.

Канал: портал. Контакт: Учебный пользователь 28-03.

Предоставлено: Отдельный случай третьего пользователя. Причина из обращения 01 для него не подтверждена. Уточнить объект, время появления и недавнее изменение; одинаковая тема не доказывает одинаковую причину.

V28-04 · График не показывает часть учебных строк

На браузере учебного профиля пользователь сообщает: «График не показывает часть учебных строк». Пользователь выполнил действие дважды и остановился, чтобы не повредить учебные данные. Ожидается, что операция «график не показывает часть учебных строк» будет обработана штатно либо сервис покажет понятное ограничение.

Канал: внутренний чат. Контакт: Учебный пользователь 28-04.

Предоставлено: График использует только видимые строки. Фильтр скрывает вторую строку, значение в исходнике присутствует.

Ожидается, что операция «график не показывает часть учебных строк» будет обработана штатно либо сервис покажет понятное ограничение.

Канал: форма поддержки. Контакт: Учебный пользователь 28-05.

Предоставлено: График использует только видимые строки. Фильтр скрывает вторую строку, значение в исходнике присутствует. Проверка на рабочем месте пользователя 05 отдельно не выполнена.

На резервном рабочем месте пользователь сообщает: «В PDF нарушены символы». После повторения действия отображается тот же симптом; перезапуск вкладки результата не изменил. Ожидается, что операция «в pdf нарушены символы» будет обработана штатно либо сервис покажет понятное ограничение.

Канал: email. Контакт: Учебный пользователь 28-06.

Предоставлено: Сверить sample.csv своей области: UTF-8, разделитель «;», код 028205, дата 2026-11-24, четыре столбца. Исходник не изменять. Если тема относится к другому файлу, это аналогичный приём, а не подтверждённая причина исходного случая.

Предоставлено: Досье: доступны только исходное сообщение и учебный контакт. Уточнить точный файл или адрес, версию программы, действие и сообщение. Проверку чужого устройства или внешней системы без доступа не объявлять выполненной.

На браузере учебного профиля пользователь сообщает: «Запрошено изменение исходных измерений». Пользователь выполнил действие дважды и остановился, чтобы не повредить учебные данные. Ожидается, что операция «запрошено изменение исходных измерений» будет обработана штатно либо сервис покажет понятное ограничение.

V28-10 · Не приложен пример строки

На тестовом терминале пользователь сообщает: «Не приложен пример строки». В сообщении нет признаков изменения реальных данных или оборудования; требуется безопасная проверка. Ожидается, что операция «не приложен пример строки» будет обработана штатно либо сервис покажет понятное ограничение. В обращении намеренно отсутствует один существенный параметр, указанный в теме; его нужно запросить до вывода.

Канал: форма поддержки. Контакт: Учебный пользователь 28-10.

Предоставлено: Существенное условие намеренно не сообщено: Не приложен пример строки. Уточнить его до вывода о причине. Объяснить, как полученный ответ повлияет на дальнейшую проверку.
