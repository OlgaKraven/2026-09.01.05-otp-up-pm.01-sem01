V03-01 · В браузере не воспроизводится звук

На резервном рабочем месте пользователь сообщает: «В браузере не воспроизводится звук». После повторения действия отображается тот же симптом; перезапуск вкладки результата не изменил. Ожидается, что операция «в браузере не воспроизводится звук» будет обработана штатно либо сервис покажет понятное ограничение.

Канал: email. Контакт: Учебный пользователь 03-01.

Предоставлено: Звук сайта заблокирован, громкость браузера 70 %, выход «Учебные динамики». Досье сообщает об успешном звуке в другом приложении.

Ожидается, что операция «в браузере не воспроизводится звук» будет обработана штатно либо сервис покажет понятное ограничение.

Предоставлено: Отдельный случай второго пользователя. Звук сайта заблокирован, громкость браузера 70 %, выход «Учебные динамики». Досье сообщает об успешном звуке в другом приложении. Самостоятельная проверка на его рабочем месте ещё не выполнена.

V03-03 · В браузере не воспроизводится звук

Канал: портал. Контакт: Учебный пользователь 03-03.

Предоставлено: Отдельный случай третьего пользователя. Причина из обращения 01 для него не подтверждена. Уточнить объект, время появления и недавнее изменение; одинаковая тема не доказывает одинаковую причину.

V03-09 · Запрошена установка неизвестной программы

На браузере учебного профиля пользователь сообщает: «Запрошена установка неизвестной программы». Пользователь выполнил действие дважды и остановился, чтобы не повредить учебные данные. Ожидается, что операция «запрошена установка неизвестной программы» будет обработана штатно либо сервис покажет понятное ограничение.

Канал: внутренний чат. Контакт: Учебный пользователь 03-09.

V03-10 · Обращение содержит только слова «ничего не работает»

На тестовом терминале пользователь сообщает: «Обращение содержит только слова «ничего не работает»». В сообщении нет признаков изменения реальных данных или оборудования; требуется безопасная проверка. Ожидается, что операция «обращение содержит только слова «ничего не работает»» будет обработана штатно либо сервис покажет понятное ограничение. В обращении намеренно отсутствует один существенный параметр, указанный в теме; его нужно запросить до вывода.

Канал: форма поддержки. Контакт: Учебный пользователь 03-10.

Предоставлено: Существенное условие намеренно не сообщено: Обращение содержит только слова «ничего не работает». Уточнить его до вывода о причине. Объяснить, как полученный ответ повлияет на дальнейшую проверку.
