Досье · Центр обслуживания посетителей

V10-01 · В форме не сохраняется черновик

На учебном ноутбуке пользователь сообщает: «В форме не сохраняется черновик». После повторения действия отображается тот же симптом; перезапуск вкладки результата не изменил. Ожидается, что операция «в форме не сохраняется черновик» будет обработана штатно либо сервис покажет понятное ограничение.

Канал: email. Контакт: Учебный пользователь 10-01.

Предоставлено: Черновик хранился в приватном окне и исчез после его закрытия. Восстановление не выполнялось.

V10-02 · В форме не сохраняется черновик

На браузере учебного профиля пользователь сообщает: «В форме не сохраняется черновик». Проблема наблюдается только в учебных данных этого пользователя; у соседа действие выполняется. Ожидается, что операция «в форме не сохраняется черновик» будет обработана штатно либо сервис покажет понятное ограничение.

Канал: телефон. Контакт: Учебный пользователь 10-02.

Предоставлено: Отдельный случай второго пользователя. Черновик хранился в приватном окне и исчез после его закрытия. Восстановление не выполнялось. Самостоятельная проверка на его рабочем месте ещё не выполнена.

V10-03 · В форме не сохраняется черновик

На тестовом терминале пользователь сообщает: «В форме не сохраняется черновик». До последнего штатного завершения работы функция открывалась без сообщения об ошибке. Ожидается, что операция «в форме не сохраняется черновик» будет обработана штатно либо сервис покажет понятное ограничение.

Канал: портал. Контакт: Учебный пользователь 10-03.

Предоставлено: Отдельный случай третьего пользователя. Причина из обращения 01 для него не подтверждена. Уточнить объект, время появления и недавнее изменение; одинаковая тема не доказывает одинаковую причину.

V10-04 · Скан документа не проходит проверку формата

На резервном рабочем месте пользователь сообщает: «Скан документа не проходит проверку формата». Пользователь выполнил действие дважды и остановился, чтобы не повредить учебные данные. Ожидается, что операция «скан документа не проходит проверку формата» будет обработана штатно либо сервис покажет понятное ограничение.

Канал: внутренний чат. Контакт: Учебный пользователь 10-04.

Предоставлено: Форма принимает PDF/PNG; scan.heic имеет тип HEIC. Переименование расширения формат не изменяет.

V10-05 · Скан документа не проходит проверку формата

На рабочем месте пользователь сообщает: «Скан документа не проходит проверку формата». В сообщении нет признаков изменения реальных данных или оборудования; требуется безопасная проверка. Ожидается, что операция «скан документа не проходит проверку формата» будет обработана штатно либо сервис покажет понятное ограничение.

Канал: форма поддержки. Контакт: Учебный пользователь 10-05.

Предоставлено: Форма принимает PDF/PNG; scan.heic имеет тип HEIC. Переименование расширения формат не изменяет. Проверка на рабочем месте пользователя 05 отдельно не выполнена.

V10-06 · Не печатается талон

На учебном ноутбуке пользователь сообщает: «Не печатается талон». После повторения действия отображается тот же симптом; перезапуск вкладки результата не изменил. Ожидается, что операция «не печатается талон» будет обработана штатно либо сервис покажет понятное ограничение.

Канал: email. Контакт: Учебный пользователь 10-06.

Предоставлено: Досье: исходный документ содержит нижнюю строку; масштаб 110 %, формат вывода меньше макета. Физическая печать не проверялась. Модель print-lab.html показывает только влияние масштаба на границы страницы.

V10-07 · Неверно выбран язык интерфейса

На браузере учебного профиля пользователь сообщает: «Неверно выбран язык интерфейса». Проблема наблюдается только в учебных данных этого пользователя; у соседа действие выполняется. Ожидается, что операция «неверно выбран язык интерфейса» будет обработана штатно либо сервис покажет понятное ограничение.

Канал: телефон. Контакт: Учебный пользователь 10-07.

Предоставлено: Досье: выбрана раскладка EN, ожидается RU. Разрешён выбор языка текущего ввода; системные политики не меняются.

V10-08 · Не открывается инструкция PDF

На тестовом терминале пользователь сообщает: «Не открывается инструкция PDF». До последнего штатного завершения работы функция открывалась без сообщения об ошибке. Ожидается, что операция «не открывается инструкция pdf» будет обработана штатно либо сервис покажет понятное ограничение.

Канал: портал. Контакт: Учебный пользователь 10-08.

Предоставлено: Досье: доступны только исходное сообщение и учебный контакт. Уточнить точный файл или адрес, версию программы, действие и сообщение. Проверку чужого устройства или внешней системы без доступа не объявлять выполненной.

V10-09 · Пользователь просит отключить проверку доступа

На резервном рабочем месте пользователь сообщает: «Пользователь просит отключить проверку доступа». Пользователь выполнил действие дважды и остановился, чтобы не повредить учебные данные. Ожидается, что операция «пользователь просит отключить проверку доступа» будет обработана штатно либо сервис покажет понятное ограничение.

Канал: внутренний чат. Контакт: Учебный пользователь 10-09.

Предоставлено: Подтверждения полномочий на чужие данные, изменение прав или отключение защиты нет. Действие не выполнять; сформулировать границу и передачу уполномоченному специалисту.

V10-10 · Не указано, с какой страницы началась ошибка

На рабочем месте пользователь сообщает: «Не указано, с какой страницы началась ошибка». В сообщении нет признаков изменения реальных данных или оборудования; требуется безопасная проверка. Ожидается, что операция «не указано, с какой страницы началась ошибка» будет обработана штатно либо сервис покажет понятное ограничение. В обращении намеренно отсутствует один существенный параметр, указанный в теме; его нужно запросить до вывода.

Канал: форма поддержки. Контакт: Учебный пользователь 10-10.

Предоставлено: Существенное условие намеренно не сообщено: Не указано, с какой страницы началась ошибка. Уточнить его до вывода о причине. Объяснить, как полученный ответ повлияет на дальнейшую проверку.
