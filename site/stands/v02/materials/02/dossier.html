Досье · Учебная часть

V02-01 · Не открывается общая папка ведомостей

На тестовом терминале пользователь сообщает: «Не открывается общая папка ведомостей». После повторения действия отображается тот же симптом; перезапуск вкладки результата не изменил. Ожидается, что операция «не открывается общая папка ведомостей» будет обработана штатно либо сервис покажет понятное ограничение.

Канал: email. Контакт: Учебный пользователь 02-01.

Предоставлено: Журнал ведомостей доступен роли «Методист», у заявителя роль «Просмотр». Полномочия на смену роли не выданы.

V02-02 · Не открывается общая папка ведомостей

На резервном рабочем месте пользователь сообщает: «Не открывается общая папка ведомостей». Проблема наблюдается только в учебных данных этого пользователя; у соседа действие выполняется. Ожидается, что операция «не открывается общая папка ведомостей» будет обработана штатно либо сервис покажет понятное ограничение.

Канал: телефон. Контакт: Учебный пользователь 02-02.

Предоставлено: Отдельный случай второго пользователя. Журнал ведомостей доступен роли «Методист», у заявителя роль «Просмотр». Полномочия на смену роли не выданы. Самостоятельная проверка на его рабочем месте ещё не выполнена.

V02-03 · Не открывается общая папка ведомостей

На рабочем месте пользователь сообщает: «Не открывается общая папка ведомостей». До последнего штатного завершения работы функция открывалась без сообщения об ошибке. Ожидается, что операция «не открывается общая папка ведомостей» будет обработана штатно либо сервис покажет понятное ограничение.

Канал: портал. Контакт: Учебный пользователь 02-03.

Предоставлено: Отдельный случай третьего пользователя. Причина из обращения 01 для него не подтверждена. Уточнить объект, время появления и недавнее изменение; одинаковая тема не доказывает одинаковую причину.

V02-04 · Печать ведомости обрезает правый край

На учебном ноутбуке пользователь сообщает: «Печать ведомости обрезает правый край». Пользователь выполнил действие дважды и остановился, чтобы не повредить учебные данные. Ожидается, что операция «печать ведомости обрезает правый край» будет обработана штатно либо сервис покажет понятное ограничение.

Канал: внутренний чат. Контакт: Учебный пользователь 02-04.

Предоставлено: В макете шесть столбцов; при масштабе 110 % последний выходит за правое поле модели страницы.

V02-05 · Печать ведомости обрезает правый край

На браузере учебного профиля пользователь сообщает: «Печать ведомости обрезает правый край». В сообщении нет признаков изменения реальных данных или оборудования; требуется безопасная проверка. Ожидается, что операция «печать ведомости обрезает правый край» будет обработана штатно либо сервис покажет понятное ограничение.

Канал: форма поддержки. Контакт: Учебный пользователь 02-05.

Предоставлено: В макете шесть столбцов; при масштабе 110 % последний выходит за правое поле модели страницы. Проверка на рабочем месте пользователя 05 отдельно не выполнена.

V02-06 · Не удаётся открыть выгрузку CSV

На тестовом терминале пользователь сообщает: «Не удаётся открыть выгрузку CSV». После повторения действия отображается тот же симптом; перезапуск вкладки результата не изменил. Ожидается, что операция «не удаётся открыть выгрузку csv» будет обработана штатно либо сервис покажет понятное ограничение.

Канал: email. Контакт: Учебный пользователь 02-06.

Предоставлено: Сверить sample.csv своей области: UTF-8, разделитель «;», код 002205, дата 2026-11-24, четыре столбца. Исходник не изменять. Если тема относится к другому файлу, это аналогичный приём, а не подтверждённая причина исходного случая.

V02-08 · Портал показывает старую страницу

На рабочем месте пользователь сообщает: «Портал показывает старую страницу». До последнего штатного завершения работы функция открывалась без сообщения об ошибке. Ожидается, что операция «портал показывает старую страницу» будет обработана штатно либо сервис покажет понятное ограничение.

Предоставлено: Досье: доступны только исходное сообщение и учебный контакт. Уточнить точный файл или адрес, версию программы, действие и сообщение. Проверку чужого устройства или внешней системы без доступа не объявлять выполненной.

V02-09 · Поступил запрос чужого пароля

На учебном ноутбуке пользователь сообщает: «Поступил запрос чужого пароля». Пользователь выполнил действие дважды и остановился, чтобы не повредить учебные данные. Ожидается, что операция «поступил запрос чужого пароля» будет обработана штатно либо сервис покажет понятное ограничение.

Канал: внутренний чат. Контакт: Учебный пользователь 02-09.

Предоставлено: Подтверждения полномочий на чужие данные, изменение прав или отключение защиты нет. Действие не выполнять; сформулировать границу и передачу уполномоченному специалисту.

V02-10 · Не приложен текст ошибки экспорта

На браузере учебного профиля пользователь сообщает: «Не приложен текст ошибки экспорта». В сообщении нет признаков изменения реальных данных или оборудования; требуется безопасная проверка. Ожидается, что операция «не приложен текст ошибки экспорта» будет обработана штатно либо сервис покажет понятное ограничение. В обращении намеренно отсутствует один существенный параметр, указанный в теме; его нужно запросить до вывода.

Канал: форма поддержки. Контакт: Учебный пользователь 02-10.

Предоставлено: Существенное условие намеренно не сообщено: Не приложен текст ошибки экспорта. Уточнить его до вывода о причине. Объяснить, как полученный ответ повлияет на дальнейшую проверку.
